# 🚀 Object-Oriented Programming (OOP)

A collection of Java sessions and assignments designed to build a strong understanding of Object-Oriented Programming (OOP) concepts.

The sessions are organized step by step, starting with Java fundamentals and progressing to practical OOP applications.

---

## 📚 Table of Contents

### 🟢 Session 1 – Java Fundamentals

#### 📌 What We Covered

- Java Classes
- Objects
- Variables
- Data Types
- Methods
- Constructors
- `this` keyword
- Creating and using Objects
- Basic Java problem solving

#### 📝 Requirements

- Create Java classes.
- Create objects from classes.
- Use constructors to initialize objects.
- Use methods to modify and access object data.
- Understand the difference between an Object and a Reference.
- Practice basic Java programming.

---

### 🟡 Session 2 – OOP Bank Account System

#### 📌 What We Covered

- Classes & Objects
- Constructors
- `this`

- `super`
- Method Overriding
- Polymorphism
- Method Overloading
- `static`
- `final`

#### 🏦 Project – Bank Account System

The session includes a simple Bank Account System implemented using Java and OOP.

The system contains:

- `BankElkhal`
- `SavingsAccount`
- `CurrentAccount`
- `Main`

#### ⚙️ Requirements

- Create different bank accounts.
- Store account information.
- Deposit money.
- Withdraw money.
- Display account information.
- Apply different withdrawal rules for each account type.
- Count the total number of accounts.
- Demonstrate inheritance.
- Demonstrate method overriding.
- Demonstrate polymorphism.
- Demonstrate method overloading.

#### 🏦 Project – Bank System

The session includes a simple Bank System designed from a UML Class Diagram.

The system contains:

- `Bank`
- `Teller`
- `Customer`
- `Account`
- `Checking`
- `Savings`
- `Loan`
- `Main`

#### ⚙️ Requirements

- Create Java classes based on the UML diagram.
- Add the required fields to each class.
- Add the required methods.
- Apply inheritance between `Account`, `Checking`, and `Savings`.
- Create objects from the different classes.
- Implement the Bank System structure shown in the UML diagram.
